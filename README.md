# Cyra Press LLC Website

Static site prepared for GitHub Pages at https://cyrapress.com.

## Before publishing

1. Confirm that `hello@cyrapress.com` is your working forwarded company email.
   If your actual address is different, replace every occurrence in:
   - index.html
   - privacy.html
   - terms.html

2. Upload all files to the root of the GitHub repository:
   - index.html
   - style.css
   - script.js
   - privacy.html
   - terms.html
   - 404.html
   - CNAME

3. Commit the changes and wait for GitHub Pages to deploy.

4. Test these URLs in a private browser window:
   - https://cyrapress.com/
   - https://cyrapress.com/privacy.html
   - https://cyrapress.com/terms.html
   - every navigation link
   - the email link

5. Only resubmit the Apple Developer enrollment after the live site has updated.

## Notes

- Do not remove the CNAME file.
- This site intentionally avoids placeholder buttons and unsupported claims.
- Update product descriptions whenever projects change.
